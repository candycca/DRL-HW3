# HW3-2 詳細規劃：Double / Dueling / Dueling+Double（Player）

> 目標：以 DQN + Replay（player mode）為 baseline，比較 Double、Dueling、Dueling+Double。

## ✅ 成功判準（收斂）
- Reward/成功率趨勢穩定或持續上升，且 loss 下降後趨於平穩。
- 變體需展現較 baseline 更穩定或更高的平均表現。

## 實驗設定（建議）
- Random seed：3 組
- 訓練回合數一致
- 設定固定探索策略（epsilon schedule）

## 實驗項目與輸出
1. **Baseline：DQN + Replay（player mode）**
   - 輸出：`outputs/hw3-2/baseline_player/`
2. **Double DQN（player mode）**
   - 輸出：`outputs/hw3-2/double_player/`
3. **Dueling DQN（player mode）**
   - 輸出：`outputs/hw3-2/dueling_player/`
4. **Dueling + Double DQN（player mode）**
   - 輸出：`outputs/hw3-2/dueling_double_player/`

### 每個實驗資料夾需包含
- `metrics.csv`、`loss.png`、`dashboard.gif`、`config.json`、`checkpoints/`

## 腳本流程（對應現有程式）
> 以 `src/run_hw3_2.py` 為主；若支援 mode 參數，依序執行四種設定。

1. 跑 baseline
2. 跑 Double DQN
3. 跑 Dueling DQN
4. 跑 Dueling + Double DQN
5. 匯總曲線與指標到 `outputs/summaries/`

## 量化指標（建議）
- 平均回饋、成功率、平均步數
- 收斂回合數（達到穩定表現的 episode）

## 討論與比較要點
- Double DQN：降低過度估計，曲線應更穩定
- Dueling DQN：更快辨識狀態價值
- Dueling+Double：兼具穩定性與效率
- 說明哪個變體最好與原因

## 報告素材清單
- 4 條 loss 曲線與對照圖
- 4 個 dashboard GIF
- 指標表格與比較結論
