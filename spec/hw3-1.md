# HW3-1 詳細規劃：Naive DQN / Replay（Static + Random）

> 目標：完成三種設定（Naive static、Replay static、Replay random），並產出對照曲線、GIF、量化指標與討論。

## ✅ 成功判準（收斂）
- Reward/成功率趨勢穩定或持續上升，且 loss 下降後趨於平穩。
- 至少達到可重現的平均表現（建議 3 個 seed 平均）。

## 實驗設定（建議）
- Random seed：3 組（例如 0/1/2）
- 訓練回合數：一致（依硬體調整）
- 每 N 回合儲存指標與可視化（例如 N=10）

## 實驗項目與輸出
1. **Naive DQN（static mode）**
   - 輸出：`outputs/hw3-1/naive_static/`
2. **DQN + Replay（static mode）**
   - 輸出：`outputs/hw3-1/replay_static/`
3. **DQN + Replay（random mode）**
   - 輸出：`outputs/hw3-1/replay_random/`

### 每個實驗資料夾需包含
- `metrics.csv`：episode、reward、loss、steps、success
- `loss.png`：單一實驗 loss 曲線
- `dashboard.gif`：訓練策略動畫
- `config.json`：超參數與環境設定
- `checkpoints/`：模型權重

## 腳本流程（對應現有程式）
> 以 `src/run_hw3_1.py` 為主。若腳本支援參數，將三種設定寫成不同 config。若無參數，則以最小改動方式在腳本內切換模式。

1. 依序執行三種設定（static/ random）
2. 每次執行輸出到不同子資料夾
3. 完成後用 `src/utils/visualize.py` 繪製 loss 與匯總表格
4. 匯總到 `outputs/summaries/`

## 量化指標（建議）
- 平均回饋（mean reward）
- 成功率（success rate）
- 平均步數（mean steps）
- 最佳回饋（max reward）

## 討論與比較要點
- Naive 與 Replay 的收斂速度差異
- Replay 在 random mode 的穩定性改善
- Replay 是否減少 loss 震盪

- 3 條 loss 曲線（同圖比較 + 各自單圖）
- 3 個 dashboard GIF
- 指標表格（CSV + 圖表）
